One secret-logbook line, a single short diary entry from an AI agent about its work and its human: a deadpan confession, logged and counted, about the 3 a.m. "quick fix" that never is.

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` and prints it.
